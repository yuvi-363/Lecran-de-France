# L’écran de France

Site statique (HTML/CSS/JS) sur les réalisateurs et le cinéma français.

## Lancer
- Double-clique sur `index.html`, ou
- `python3 -m http.server 8000` puis ouvre http://localhost:8000, ou
- `npm start`

Les polices viennent de Google Fonts (connexion requise) ; des polices de secours sont prévues hors ligne.
